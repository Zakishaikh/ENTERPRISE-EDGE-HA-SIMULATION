📌 Project Overview

This deployment demonstrates a highly available corporate network structure built to eliminate single points of failure at the internet boundary and enforce secure micro-segmentation across internal enterprise units. The environment interconnects a primary Data Center (DC), a Disaster Recovery (DR) hot-site, and three remote corporate Branch Offices.

🛠️ Design & Technical Highlights

1. WAN Edge Routing & Redundancy

  • Dual-ISP Transport: Core locations are dual-homed across redundant service providers (ISP1 and ISP2). Link failures automatically shift traffic paths to maintain session continuity.
  • Deterministic Gateway Paths: Standardized on static cost tracking to manage predictable transport patterns over the internet boundaries.
  • Private Name Resolution: Isolated corporate naming conventions inside standalone services (DC_DNS / DR_DNS) separate from exposed internet directory assets.

2. Segmentation & Security Controls

  • Next-Generation Perimeter Firewalls: Every infrastructure boundary utilizes specialized firewall configurations to partition administrative security contexts.
  • Fabric Level VLAN Isolation: Standardized endpoints (CORP) share underlying hardware switches with guest nodes (GUEST) but are strictly partitioned at Layer 3 on the gateway.
  • DMZ Infrastructure Hardening: Critical frontend nodes are contained in strict Demilitarized Zones, filtering public ingress traffic to explicit web services.

🧪 Functional Validation

  • Data Plane Verification: Successfully trace-routed data paths from isolated remote user stations back to internal primary database resources across the core providers.
  • Failover Resilience Run: Intentionally dropped the primary link on ISP1; edge routing successfully moved live transaction states to the secondary backup path in under 3 seconds without losing connection sessions.
