📌 Project Infrastructure Overview

This deployment validates a highly available corporate infrastructure designed to rule out single points of failure at the enterprise routing layer and apply hard micro-segmentation policies across internal environments. The simulated design flawlessly interconnects a primary Corporate Data Center (DC), a synchronized Disaster Recovery (DR) hot-site, and three remote Branch Offices.

🛠️ Core Engineering Specifications

1. Multi-Provider Edge Redundancy

  • Active Dual-ISP Uplinks: Sites route traffic concurrently via independent transit paths (ISP1 and ISP2). Outages trigger instant, deterministic failover events to guarantee infrastructure uptime.
  • Path Metrics Control: Integrated precise link cost properties directly across the border interfaces to manage standard routing behavior symmetrically.
  • Private Subnet Directory: Configured dedicated localized lookup environments (DC_DNS / DR_DNS) to shield production infrastructure assets from public scanning grids.

2. Zoning & Traffic Micro-Segmentation

  • Edge Next-Gen Firewalls: Deployed perimeter security clusters managing isolated administrative contexts for every network transition.
  • Branch Isolation: Segmented end-user devices into dedicated CORP_USERS and GUEST_USERS VLANs using Cisco IOS-XE switches to prevent lateral movement.
  • DMZ Hardening: Isolated critical servers (DC_WEB, DC_APP, DC_DB) into strictly monitored zones with limited ingress permissions.
